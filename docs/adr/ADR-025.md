# ADR-025: HPDMA1 高性能 DMA

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #30
> 验证级别: MEASURED

实现 HPDMA1（高性能 DMA）驱动，用于高带宽外设
（LTDC、DCMIPP、NPU）的大数据量传输。

## 上下文

STM32N6 有 HPDMA1（高性能 DMA），与 GPDMA 不同，
HPDMA 专为高带宽外设设计，支持更高传输速率。
DS14791 Section 12: HPDMA。

HPDMA 用于：
- LTDC 帧缓冲传输（ADR-031）
- DCMIPP 摄像头数据（ADR-033）
- NPU 数据搬运（ADR-036）

## 决策

HPDMA 在 EdgeSight 中由 DCMIPP 和 VENC 硬件模块内部使用，
NuttX 驱动层不直接编程 HPDMA 通道。

- **DCMIPP** (摄像头): 内部自动使用 HPDMA 搬运帧数据到 SRAM
- **VENC** (视频编码): 内部自动使用 HPDMA 搬运编码数据
- **NPU**: 通过 ST 中间件管理数据搬运，不需要 NuttX DMA API

因此不实现独立的 HPDMA NuttX 驱动。如果后续需要 LTDC 帧缓冲
DMA 传输（显示功能），再考虑添加 HPDMA 通道分配逻辑。

## 设计

### 模块架构

```
HPDMA1 (高性能 DMA)
├── 通道特性
│   ├── 更高总线带宽
│   ├── 支持 2D 传输 (LTDC/DCMIPP)
│   └── 链表模式 (Linked-list)
│
├── 通道分配
│   ├── CH0-3: LTDC 帧缓冲
│   ├── CH4-7: DCMIPP 摄像头
│   └── CH8-11: NPU 数据
│
└── 与 GPDMA 的区别
    ├── GPDMA: 通用外设 (SPI/I2C/UART)
    └── HPDMA: 高带宽 (Display/Camera/NPU)
```

### NuttX 框架对接

```
与 GPDMA 相同的 API 接口:
  arm_dma_allocate(ch)
  arm_dma_free(ch)
  arm_dma_start(ch, cfg)
  arm_dma_stop(ch)

2D 传输配置:
  cfg.src_width  = line_width
  cfg.src_lines  = num_lines
  cfg.src_stride = line_stride
```

## 理由

HPDMA 通道由 DCMIPP/VENC/NPU 硬件流水线自动管理，
ST 中间件已封装了通道分配和数据搬运逻辑。
在 NuttX 侧重复实现会增加复杂度且可能与硬件流水线冲突。
保持简洁，让专用硬件做专用事。
