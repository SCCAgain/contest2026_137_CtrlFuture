# ADR-021: FMC 灵活存储控制器

## 状态

Proposed

## Phase

P2

## 目标

> GitHub Issue: #26
> 验证级别: MEASURED

实现 STM32N6 FMC（灵活存储控制器）驱动，
支持连接 SRAM、NOR Flash、NAND Flash 等并行存储器。

## 上下文

STM32N6 的 FMC 控制器提供并行存储器接口，
支持多种存储器类型和时序配置。
DS14791 Section 36: FMC。

FMC 可用于连接：
- 外部 SRAM（扩展内存）
- NOR Flash（代码存储）
- NAND Flash（大容量存储）

## 决策

EdgeSight 不使用 FMC：

本项目使用 XSPI (ADR-019) 而非 FMC 访问外部存储器。
STM32N6570-DK 开发板的外部 Flash 通过 XSPI2 连接，
没有使用 FMC 并行接口的外设。

此 ADR 标记为低优先级，仅在需要外接 PSRAM 扩展时实现。
当前 4.2MB SRAM + XSPI Flash 组合满足 EdgeSight 需求。

## 设计

### 模块架构

```
FMC 控制器
├── 存储器类型
│   ├── SRAM/PSRAM
│   ├── NOR Flash
│   ├── NAND Flash
│   └── SDRAM (如有)
│
├── 时序配置
│   ├── 地址建立/保持时间
│   ├── 数据建立/保持时间
│   └── 总线周转时间
│
└── 地址空间
    ├── Bank1: NOR/SRAM (0x60000000)
    ├── Bank2: NAND (0x70000000)
    └── Bank3: NAND (0x80000000)
```
