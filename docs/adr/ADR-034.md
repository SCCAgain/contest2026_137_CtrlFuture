# ADR-034: CSI-2 MIPI 接口

## 状态

Proposed

## Phase

P4

## 目标

> GitHub Issue: #39
> 验证级别: MEASURED

实现 STM32N6 CSI-2（MIPI Camera Serial Interface 2）驱动，
支持 MIPI CSI-2 协议的物理层和协议层。

## 上下文

STM32N647X0 内置 CSI-2 接口，特性：
- MIPI CSI-2 v2.1 协议
- 支持 2-lane / 4-lane 配置
- 数据速率最高 2.5Gbps/lane
- 支持 RAW8/10/12、YUV422、RGB888
- D-PHY 物理层

DS14791 Section 40: CSI-2。
CSI-2 是现代摄像头模组的标准接口。

## 决策

EdgeSight 摄像头接口方案：

1. **2-lane MIPI CSI-2**: STM32N6570-DK 板载 IMX335 sensor 使用 2-lane
2. **数据格式**: RAW10 输入，由 DCMIPP ISP 处理为 RGB/YUV
3. **数据速率**: 2-lane x 1.5Gbps = 3Gbps 总带宽，满足 5MP@30fps
4. **不直接操作 CSI-2**: ST 的 CMW_CAMERA 中间件封装了 CSI-2 初始化，
   NuttX 驱动层只需调用 CMW 接口即可（参考 ADR-033 DCMIPP）
5. **D-PHY 配置**: 由 HAL_CSI_Init() 自动完成，无需手工配置

CSI-2 与 DCMIPP 的关系：
```
Camera Sensor → CSI-2 (D-PHY) → DCMIPP (ISP + 双管线) → SRAM
```

CSI-2 不需要独立的 NuttX 驱动，作为 DCMIPP 初始化的一部分被自动配置。

## 设计

### 模块架构

```
CSI-2 接口
├── D-PHY 物理层
│   ├── 差分时钟对 (CLK+/CLK-)
│   ├── 数据差分对 (D0+/D0- ... D3+/D3-)
│   ├── LP 模式 (低功耗, 命令)
│   └── HS 模式 (高速, 数据)
│
├── 协议层
│   ├── 包格式 (Start/End/DataType)
│   ├── 虚拟通道 (VC0-VC3)
│   ├── CRC 校验
│   └── ECC 校验
│
└── 数据类型
    ├── RAW6/7/8/10/12/14
    ├── YUV422 (8/10-bit)
    ├── RGB565/888
    └── User-Defined
```

### NuttX 框架对接

```
CSI-2 作为 DCMIPP 输入:
  csi_init(lanes, data_rate)
  → D-PHY 初始化
  → 协议层配置
  → DCMIPP (ADR-033) 接收数据

摄像头模组集成:
  OV5640 → CSI-2 → DCMIPP → 帧缓冲
  IMX335 → CSI-2 → DCMIPP → 帧缓冲
```

### 数据流

```
数据接收:
  CMOS 传感器 → D-PHY (HS 模式)
    → 协议层解析 (包头/CRC)
    → 虚拟通道分离
    → DCMIPP 像素管线
    → ISP 处理 → 帧缓冲
