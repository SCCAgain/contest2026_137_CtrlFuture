实现 STM32N6 DTS（Digital Temperature Sensor）驱动，

## 上下文

STM32N647X0 内置数字温度传感器（DTS），特性：
- 测量芯片结温
- 数字输出（无需 ADC）
- 可配置采样率
- 过温/低温中断

DS14791 Section 24: Digital temperature sensor (DTS)。
DTS 用于芯片热管理、NPU 热保护、系统健康监测。

## 决策

使用 DTS 进行 CPU 芯片结温监测，用于显示屏状态叠加层（stats overlay）：

- **采样模式**: 连续测量（Continuous），1Hz 周期读取
- **用途**: 在 LCD 叠加层显示当前 CPU 温度（如 "CPU: 52.3C"）
- **告警阈值**: 高温 85°C 触发中断，回调中降低 NPU 推理频率
- **初始化位置**: `board_late_initialize()` 中调用
- **NuttX 接口**: 注册为 `/dev/temp0`，应用层周期性 read() 获取温度值

不使用低温告警（设备部署在室内环境）。

## 设计

### 模块架构

```
DTS (数字温度传感器)
├── 测量范围
│   ├── -40°C ~ +125°C
│   └── 分辨率 0.1°C (典型)
│
├── 工作模式
│   ├── 单次测量 (One-shot)
│   ├── 连续测量 (Continuous)
│   └── 低功耗采样
│
└── 中断/告警
    ├── 高温阈值 (THIGH)
    ├── 低温阈值 (TLOW)
    └── 中断输出 (TS_INT)
```

### NuttX 框架对接

```
NuttX 温度传感器框架:
  sensor_register("/dev/temp0", &dts_sensor)

应用层:
  fd = open("/dev/temp0", O_RDONLY)
  read(fd, &sensor_data, sizeof(sensor_data))
  → sensor_data.temperature (单位: 0.01°C)

过温保护:
  dts_set_threshold(thigh: 85°C)
  → 超过阈值触发中断
  → 回调: 降低 NPU 频率 / 系统保护

## 理由

NPU 满载推理时芯片温度较高，DTS 监测可防止过温损坏并提供用户可见状态。
1Hz 采样率足够反映温度趋势，不会给 CPU 带来额外负担。
DTS 无需 ADC 通道，硬件独立，驱动简单可靠。
